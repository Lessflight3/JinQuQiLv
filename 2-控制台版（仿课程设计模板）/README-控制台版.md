# 《晋曲棋旅》控制台版（仿课程设计报告模板的风格）

这个版本是照着老师给的 `C++课程设计报告（模板）.doc` 里那段示例代码写的：
**单文件、纯控制台、菜单驱动、数据存文件、中文注释**——就是典型的课程设计写法。

## 一、和模板代码的对应关系

| 模板里的“图书信息管理系统” | 本程序 | 作用 |
| --- | --- | --- |
| `class Book`（图书类） | `class Player`（玩家类）、`class Land`（地块类） | 描述一条数据 |
| `class BDatabase`（图书库类） | `class Game`（游戏类） | 管理数据、提供各种功能 |
| `struct` 无 | `struct Quiz`（题目） | 把一道题的几个字段打包 |
| 菜单 `switch(choice)` | 同样的 `switch` 菜单 | 主菜单选择功能 |
| `book.txt` 存图书数据 | `jinquqilv_record.txt` 存战绩 | **用文件保存数据** |
| `fstream file("book.txt", ios::in)` | `ofstream fout(..., ios::app)`、`ifstream fin(...)` | 文件读写 |
| 每个成员后面加中文注释 | 同样每个成员都加中文注释 | 方便阅读 |
| `setw()` 对齐表格 | 同样用 `setw()` 打印棋盘 | 输出整齐 |

> 唯一不同的是：模板用的是 `#include<iostream.h>` 这种**很老的编译器写法**（VC6 / Turbo C++ 时代），
> 现在的编译器（g++ / VS2019+）不支持。所以本程序用标准写法 `#include <iostream>` + `using namespace std;`，
> **结构和功能完全一样**，但能正常编译。

## 四、怎么编译运行

**方法一（双击）**：直接双击 `jinquqilv.exe`

**方法二（用 g++ / MinGW 命令行）**：

```bat
g++ -std=c++17 jinquqilv.cpp -o jinquqilv.exe
jinquqilv.exe
```

**方法三（用 Dev-C++ / Visual Studio / Qt Creator）**：
新建一个空的控制台工程，把 `jinquqilv.cpp` 的内容粘进去，编译运行即可（**不需要 Qt**，纯 C++ 标准库）。

## 五、游戏规则（控制台版）

1. 两位玩家各有 1000 元，都从 0 号格（起点）出发；**棋盘共 24 格**（1 个起点 + 15 个普通地块 + 8 个晋剧答题地块）
2. 轮流按回车掷骰子（1~6 点），顺时针向前走，走满 24 格回到起点
3. 走到不同格子：
   - **起点**：领 100 元
   - **无人买的地块**：输入 y 就买下（钱够才买得起）
   - **自己的地块**：什么也不发生
   - **别人的地块**：自动付租金给地主
   - **晋剧答题地块**：从题库里随机抽一道晋剧题，输入 A/B/C/D，答对 +100 元、答错 −100 元
4. 现金变成负数就破产出局，最后剩下的人获胜
5. 每局结束后，结果会自动追加保存到 `jinquqilv_record.txt`，主菜单选「3. 历史战绩」可以查看

### 题库说明（重要）

控制台版内置 **44 道题**，来自完整版的题库，只取**文字就能作答**的两类：

| 类别 | 题数 | 为什么能收进控制台版 |
| --- | --- | --- |
| 晋剧常识题 | 21 道 | 纯文字题目 |
| 唱段识剧目 | 23 道 | 题面给的是唱词片段与剧情线索，不用听音频也能判断 |

另外两类（**听曲牌识曲牌** 21 道、**看图识戏曲** 21 道）没有收进来，因为控制台里既放不了音频也显示不了图片，
那两类请用图形界面版（`桌面\改进版\直接运行\JinQuQiLvSimple.exe`）。

## 六、想改点什么

| 想改什么 | 改哪里 |
| --- | --- |
| 棋盘格子（名字、价格、租金） | `Game::initGame()` 里那一串 `board[..].init(...)`（共 24 行） |
| 初始金钱 | 全局常量 `START_MONEY`（现在是 1000） |
| 晋剧题库 | 文件上部的 `static const Quiz g_quizBank[QUIZ_COUNT]` 数组 |
| 骰子点数 | `Game::playOneTurn()` 里的 `randomInt(1, 6)` |
| 答题奖惩金额 | 全局常量 `QUIZ_RIGHT` / `QUIZ_WRONG` |
| 战绩记录文件名 | `Game::saveRecord()` 与 `Game::showHistory()` 里的文件名 |
