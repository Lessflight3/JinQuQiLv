# 晋曲棋旅 — 晋剧文化主题大富翁（Qt 6 课程设计）

2~4 名玩家掷骰子、买地收租；踩到「晋剧文化地块」时按类别抽题作答，
答对奖励、答错惩罚，直到只剩一名未破产玩家。

## 一、本版亮点

| 项目 | 说明 |
| --- | --- |
| 棋盘比例 | 24 格 = 1 起点 + **15 个山西文化地标** + **8 个晋剧文化地块**（四大类题目各占 2 块） |
| 题库 | **四类共 86 道题**：①晋剧常识 21 ②听曲牌识曲牌 21 ③听唱段识剧目 23 ④看图识戏曲 21 |
| 题目分布 | 开局时四大类**随机散布**到 8 个晋剧地块上（每类 2 块），棋盘格右上角显示类别角标（常识/曲牌/唱段/图片） |
| 界面背景 | 主界面与答题弹窗均为「晋剧舞台 + 山西山水古建」融合背景（程序绘制） |
| 地域风貌 | 每个普通地块落地时弹出该地标的地域风貌图（悬空寺、壶口瀑布、云冈石窟、平遥古城……） |
| 看图题 | 21 幅戏曲元素插画（脸谱、髯口、水袖、翎子、马鞭、晋胡、蟒袍、靠衣、厚底靴……） |
| 配乐 | 进入游戏循环播放晋剧曲牌《小开门》，可一键开关（按钮或按 M 键） |
| 文字排版 | 所有文字按可用空间自动缩放/省略；窗口按屏幕自适应，面板高度不再溢出 |
| 快捷键 | 空格 / 回车 = 掷骰子，M = 开关配乐 |

## 三、构建与运行

**Qt Creator**：打开 `JinQuQiLv.pro` → 选择 `Desktop Qt 6.x MinGW 64-bit` 套件 → `Ctrl+R`。

**工程路径**：建议放在纯英文路径下（如 `C:\Users\lenovo\Desktop\The song and journey of Jin`）。
工程内部所有头文件都用**相对路径**包含（如 `#include "../model/game.h"`），
`.pro` 里也不再设置 `INCLUDEPATH`，因此编译命令中不会出现工程绝对路径；
即便放在中文目录下，也不会再出现 `model/game.h: No such file or directory`。

**命令行（MinGW）**：

```bat
cd /d "C:\Users\lenovo\Desktop\The song and journey of Jin"
D:\QT\6.12.0\mingw_64\bin\qmake.exe JinQuQiLv.pro CONFIG+=release
D:\QT\Tools\mingw1310_64\bin\mingw32-make.exe -j4
release\JinQuQiLv.exe
```

**命令行参数（可选）**：

```bat
JinQuQiLv.exe --players 4      :: 跳过开局对话框，直接 4 人开局
JinQuQiLv.exe --selfcheck      :: 启动后自检界面文字是否放得下，报告写入 layout_selfcheck.txt
JinQuQiLv.exe --no-music       :: 不自动播放背景音乐
```

## 四、玩法规则

| 规则 | 数值 |
| --- | --- |
| 玩家数量 | 2~4 人 |
| 初始资金 | 3000 元 |
| 骰子点数 | 1~6 |
| **戏班开销** | 每回合开演前支付：25 元起，每过 10 回合 +5 元，上限 120 元；交不出即散班出局 |
| 经过起点补贴 | +100 元 |
| 普通地块 | 15 个山西文化地标（含八泉峡），售价 120~260 元，租金约为售价的 **60%** |
| 连片加成 | 地主每多持有一块地，名下所有地块租金 **+25%** |
| 晋剧文化地块 | 8 个，四类题目各占 2 块，答对 **+100** 元、答错 **−150** 元 |
| 破产条件 | 现金不足以支付租金 / 答题罚款 / 戏班开销，出局后名下地产重新待售 |
| 获胜条件 | 场上只剩 1 名未破产玩家 |

> 经济参数经过对局模拟调优（见 `tests/sim.cpp`）：200 局 × 3 种答题水平，**结束率 100%**。
> 4 人局中位数：每题都答对 165 次出手（≈20 分钟）、一半答对 86 次（≈12 分钟）、
> 每题都答错 58 次（≈8 分钟）；金钱有明显起伏（答题 +100、交租 −85~−190、每回合 −25 起），
> 既不会"半小时打不完"，也不会"还没买地就结束"。

## 四、题目设计原则

**题干中绝不出现答案的用词**（含答案里的连续两字片段），例如：

- ❌ 旧题：「王宝钏寒窑苦守、薛平贵归来后**算粮**、**登殿**的故事，对应剧目是？」（答案《算粮登殿》直接写在题干里）
- ✅ 新题：「**薛平贵**离家十八年归来，与苦守寒窑的**王宝钏**相认，随后夫妻一同入朝、受封团圆。这是哪一出？」
  （人物、唱词、行当等线索**全部保留**，只把剧名本身从题干里去掉）

`听唱段识剧目` 类改为**唱词片段 / 剧情线索**两种提问方式，`听曲牌识曲牌` 只给音乐特征与
使用场景，`看图识戏曲` 只给画面描述。工程里附带了自动检查脚本的思路：
逐题把正确选项与题干做子串比对，当前 **86 道题 0 处泄漏**（检查输出见课程设计报告 5.4 节）。

## 五、如何换成你自己的照片和音频（无需改代码）

把文件放进工程目录的 `resources/` 下对应子目录即可，程序启动时会自动优先使用：

| 想替换的内容 | 放置位置 | 文件名 |
| --- | --- | --- |
| 主界面背景 | `resources/backgrounds/` | `main_bg.jpg`（或 .png） |
| 答题弹窗背景 | `resources/backgrounds/` | `quiz_bg.jpg` |
| 地标照片 | `resources/places/` | `jinci.jpg`、`hukoupubu.jpg`、`xuankongsi.jpg` 等（见该目录 README） |
| 看图题图片 | `resources/quiz/` | `mask_red.jpg`、`sleeve_water.jpg` 等（见该目录 README） |
| 配乐《小开门》 | `resources/audio/` | `xiaokaimen.wav`（未装 Qt Multimedia 时只支持 WAV） |
| 题目音频 | `resources/audio/` | `dajinzhi.mp3`（《打金枝》唱段）、`xiaokaimen.mp3`（曲牌）等 |

没有放置素材时：背景与插画使用程序绘制的版本，音频题显示文字线索，功能不受影响。
